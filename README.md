# AeroFuel Calc

Офлайн десктопний додаток для автоматизації розрахунку чистого часу польоту та необхідного об'єму авіаційного пального з урахуванням обов'язкових резервів.

## Основні можливості
- Введення відстані маршруту (км або морські милі), крейсерської швидкості та базової витрати пального.
- Налаштування відсотка навігаційного та компенсаційного резерву.
- Автоматична перевірка коректності введених даних (захист від від'ємних чисел, тексту та ділення на нуль).
- Графічний інтерфейс українською мовою.

## Технології
- **Мова:** Python 3
- **GUI:** Tkinter
- **Середовище розробки:** Visual Studio Code

## Запуск
```bash
python3 main.py
